Explanation / 説明
한국어
이 프로그램은 Penrose P3와 Ammann–Beenker 타일링의 실제 꼭짓점과 실제 타일 edge를 이용해 바둑을 둘 수 있도록 만든 버전입니다. 각 꼭짓점은 착점이고, 두 꼭짓점이 같은 타일의 변으로 연결되어 있을 때만 서로 인접한 것으로 취급됩니다.

1. Game mode
Vs AI에서는 사용자가 흑, AI가 백을 둡니다. Local manual에서는 AI가 완전히 꺼지고 흑과 백이 자동으로 번갈아 차례를 갖습니다. 따라서 혼자 양쪽 수를 직접 두면서 연구용으로 국면을 만들 수도 있고, 친구와 같은 화면에서 번갈아 둘 수도 있습니다.

2. Board generation
Generate standard board는 중심부의 표준적인 유한 patch를 만듭니다. Generate random patch는 훨씬 큰 Penrose 또는 Ammann–Beenker tiling을 먼저 생성한 뒤, 그 내부의 임의 위치를 중심으로 일부를 잘라 새로운 반면을 만듭니다. Random patch는 Circle, Square, Regular polygon 중에서 고를 수 있고, polygon의 경우 변의 개수도 지정할 수 있습니다. 최소 site 수를 360 이상으로 지정하면 해당 조건을 만족할 때까지 patch 크기를 자동으로 키웁니다. 경계에서 생긴 degree-1 꼭짓점은 제거하고 마지막에는 가장 큰 연결 성분만 남깁니다.

3. Rules and scoring
착수, 연결된 돌무리, liberty, 포획, 자살수 금지, positional superko를 구현했습니다. 계가 규칙은 두 가지를 선택할 수 있습니다. Korean / Japanese는 territory scoring으로, 흑과 백의 집 + 잡은 돌 + 죽은 상대 돌을 계산하며 백 komi는 6.5입니다. Chinese는 area scoring으로, 살아 있는 자기 돌 + 자기 영역을 계산하며 백 komi는 7.5입니다.

4. Score review와 죽은돌
Enter score review를 누르면 대국을 즉시 끝내는 대신 계가 검토 모드로 들어갑니다. 이 상태에서는 반상 위의 연결된 돌무리를 클릭해 죽은돌로 표시하거나 다시 살릴 수 있습니다. 죽은돌은 반투명으로 표시되고 빨간 X가 겹쳐 보입니다. 검토 모드에서는 흑집과 백집 marker도 반상 위에 직접 표시됩니다. 검토가 끝나면 Finalize score로 최종 점수를 확정하고, 아직 더 두고 싶다면 Resume play로 다시 대국으로 돌아갈 수 있습니다. 두 번 연속 pass해도 자동으로 score review에 들어갑니다.

5. Position estimate
평상시 패널의 형세판단은 최종 계가가 아니라 대략적인 추정입니다. 현재 놓인 돌을 직접 세고, 빈 site는 그래프상의 거리 기반 영향력을 이용해 흑/백/중립으로 나눕니다. 사활을 완전히 푸는 기능은 아니므로 복잡한 국면에서는 실제 결과와 차이가 날 수 있습니다. Score review에 들어가면 이 패널은 추정값 대신 실제 계가 결과를 보여줍니다.

6. 화면 조작
빈 착점을 클릭하면 돌을 놓고, 드래그하면 반면을 이동하며, 마우스 휠로 확대/축소할 수 있습니다. Fit board는 현재 반면 전체가 화면에 들어오도록 자동으로 맞춥니다. Undo는 직전 수를 되돌리며, AI 모드에서는 사람이 다시 둘 차례가 되도록 필요한 수만큼 되돌립니다.

7. Light / Dark mode
Appearance 메뉴에서 Dark mode와 Light mode를 선택할 수 있습니다. 이 기능은 반면의 기하학이나 규칙에는 영향을 주지 않고, 패널·입력창·버튼·보드 배경의 시각적 테마만 바꿉니다. 밝은 환경에서는 Light mode, 어두운 환경에서는 Dark mode를 사용하면 가독성이 좋아집니다.
English
This program lets you play Go on the actual vertex-edge graphs of Penrose P3 and Ammann–Beenker tilings. Each tile vertex is a playable point, and two points are adjacent only when they are connected by an actual tile edge.

1. Game mode
In Vs AI, you play Black and the heuristic AI plays White. In Local manual, the AI is completely disabled and Black/White alternate automatically. This is useful either for playing locally with a friend or for manually constructing positions by yourself.

2. Board generation
Generate standard board creates a finite central patch. Generate random patch first generates a much larger Penrose or Ammann–Beenker tiling and then cuts out a board around a randomly selected interior position. The patch can be a circle, square, or regular polygon; polygon mode also lets you choose the number of sides. If a minimum site count such as 360 is requested, the patch is enlarged automatically until the requirement is satisfied. Degree-1 boundary vertices are pruned, and only the largest connected component is retained.

3. Rules and scoring
The program implements legal moves, connected groups, liberties, captures, suicide prevention, and positional superko. Two scoring systems are available. Korean / Japanese uses territory scoring: territory + prisoners + marked dead opponent stones, with White komi 6.5. Chinese uses area scoring: living stones + controlled territory, with White komi 7.5.

4. Score review and dead stones
Press Enter score review to inspect the final position before fixing the result. In score review, click any connected group to mark or unmark it as dead. Dead stones become semi-transparent and are overlaid with a red X. Black and White territory markers are also shown directly on the board. Press Finalize score to lock in the result, or Resume play to continue the game. Two consecutive passes also enter score review automatically.

5. Position estimate
During ordinary play, the panel shows a rough positional estimate, not a full life-and-death solution. Stones are counted directly, while empty sites are provisionally assigned by graph-distance influence to Black, White, or neutral. Therefore unsettled positions can differ substantially from the true final score. Once score review is entered, the panel switches from estimation to the reviewed scoring result.

6. Board controls
Click an empty vertex to play, drag to pan, and use the mouse wheel to zoom. Fit board rescales the full board to fit the viewport. Undo reverts the latest move; in AI mode it rewinds far enough to return control to the human player.

7. Light / Dark mode
Use the Appearance menu to switch between Dark mode and Light mode. This does not change the board geometry, game state, or scoring rules; it only changes the visual theme of the panels, controls, text, and board background. Light mode is often easier to read in bright environments, while Dark mode is more comfortable in dim environments.
日本語
このプログラムでは、Penrose P3 および Ammann–Beenker タイリングの実際の頂点・辺グラフ上で碁を打つことができます。 各タイルの頂点を着点とし、実際のタイルの辺で結ばれている頂点同士だけを隣接点として扱います。

1. Game mode
Vs AI ではユーザーが黒、ヒューリスティック AI が白を打ちます。 Local manual では AI は完全に無効になり、黒と白の手番が自動的に交互に切り替わります。 そのため、友人と同じ画面で対局する用途にも、一人で両方の色を操作して局面を作る用途にも使えます。

2. Board generation
Generate standard board は中心付近の有限パッチを生成します。 Generate random patch は、まずより大きな Penrose または Ammann–Beenker タイリングを生成し、 その内部からランダムな位置を選んで盤面を切り出します。 パッチ形状は Circle、Square、Regular polygon から選択でき、 polygon の場合は辺の数も指定できます。 最小 site 数を 360 などに設定すると、その条件を満たすまでパッチサイズを自動的に拡大します。 境界に生じた degree-1 頂点は除去し、最後に最大の連結成分のみを残します。

3. Rules and scoring
着手、連結グループ、liberty、取り、自殺手禁止、positional superko を実装しています。 計算方式は 2 種類から選べます。 Korean / Japanese は territory scoring で、地 + 取った石 + 死に石を数え、白コミは 6.5目です。 Chinese は area scoring で、生きている自分の石 + 自分の領域を数え、白コミは 7.5目です。

4. Score review と死に石
Enter score review を押すと、最終結果を確定する前の確認モードに入ります。 この状態では、連結した石のグループをクリックして死に石としてマークしたり、元に戻したりできます。 死に石は半透明表示になり、赤い X が重ねて表示されます。 また、黒地・白地の marker も盤上に直接表示されます。 Finalize score で結果を確定し、まだ続けたい場合は Resume play で対局に戻れます。 2 回連続で pass した場合も自動的に score review に入ります。

5. Position estimate
通常対局中のパネルは、最終計算ではなく 概算の形勢判断です。 現在の石はそのまま数え、空点はグラフ距離に基づく influence によって黒・白・中立へ暫定分類します。 生死判定を完全に解く機能ではないため、未確定な局面では実際の最終結果と大きく異なる場合があります。 Score review に入ると、パネルは概算ではなく実際の計算結果を表示します。

6. Board controls
空いている頂点をクリックすると着手し、ドラッグで盤面を移動し、マウスホイールで拡大・縮小できます。 Fit board は盤面全体が画面に収まるよう自動調整します。 Undo は直前の手を戻し、AI モードでは再びユーザーの手番になるところまで必要な分だけ戻します。

7. Light / Dark mode
Appearance メニューから Dark mode と Light mode を切り替えられます。 この機能は盤面の幾何、局面、ルールには影響せず、パネル・入力欄・ボタン・文字・盤面背景などの見た目だけを変更します。 明るい環境では Light mode、暗い環境では Dark mode を使うと見やすくなります。
